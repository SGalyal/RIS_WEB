## 4. Сценарий в одно предложение

Кто создаёт → кого назначают → кто меняет статус:
Заместитель руководителя создает договор -> Заместитель руководителя назначает исполнителя -> исполнитель заполняет данные, создает заявки и меняет их статус

## 7. Запас под ВКР

Не меньше **четырёх** пунктов **из разных категорий** (данные и процессы · интеграции · масштабирование). В семестре не делают.

1. Интеграция с 1С
2. Сканирование документов с помощью компьютерного зрения
3. Автозаполнение данных в 1С
4. ИИ-ассистент
